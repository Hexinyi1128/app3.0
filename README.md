# 跳岛 · ISLAND HOP

面向 20-30 岁「奥德赛时期」年轻人的线下职业微体验预约平台高保真 Web 原型。React + Vite + Tailwind CSS，移动优先（375px 视口）。

## 运行

```bash
npm install
npm run dev
```

构建：`npm run build`。需要 Node.js 18+。

## 交互流程

登录调研（2 步）→ 首页选岛 → 地图找附近门店 → 详情页选三档体验 → 预约 → 体验中任务打卡 → 体验日记 → 离岛 / 想再登岛结果 → 跳岛日志。底部「+」可快速跳转；结果页可预览另一种结果。

## 结构

- `src/data/islandHop.json`：用户、岛、门店/导师、任务、日记选项、日志种子数据、推荐信号，全部为模拟数据。
- `src/data/recommend.js`：结果判定、相邻职业推荐、偏好画像与洞察生成。后续接后端时只需替换数据层。
- `src/components/ui/`：胶囊按钮、卡片、胶囊标签、开关、字符圆环、渐变头部、底部导航、toast 等复用组件。
- `src/components/screens/`：8 个业务页面。
- `src/App.jsx`：页面状态机与全流程串联。

文案遵循跳岛词汇体系：登岛 / 离岛 / 想再登岛 / 跳岛日志 / 推荐下一座岛 / 跳岛洞察。
